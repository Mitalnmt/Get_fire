📚 HƯỚNG DẪN CHI TIẾT (3 BƯỚC ĐƠN GIẢN)
🔹 BƯỚC 1: Tải PDF có mật khẩu về máy
  1. Mở trang PDF trên digital.lib.ueh.edu.vn
  2. Nhấn Ctrl + S (hoặc chuột phải → Lưu trang)
  3. Chọn nơi lưu → Click "Lưu"
  4. ✅ File PDF có mật khẩu đã được lưu về máy
🔹 BƯỚC 2: Lấy mật khẩu để mở PDF
  1. Copy URL từ thanh địa chỉ của trang PDF (Ctrl + C)
  2. Paste vào ô "Nhập URL hoặc bitsid" bên trên
  3. Click nút "🔍 Extract Password"
  4. Click nút "Copy" để copy mật khẩu
  5. ✅ Mật khẩu đã được copy vào clipboard
🔹 BƯỚC 3: Mở PDF và lưu bản không mật khẩu
  1. Mở file PDF vừa tải (bước 1) bằng Adobe Reader hoặc Chrome
  2. Khi hỏi mật khẩu → Nhấn Ctrl + V để paste mật khẩu
  3. PDF đã mở! Bây giờ nhấn Ctrl + P để in
  4. Trong hộp thoại In → Chọn "Lưu dưới dạng PDF" hoặc "Microsoft Print to PDF"
  5. Click "Lưu" → Chọn tên file mới
  6. ✅ File PDF mới KHÔNG CÓ MẬT KHẨU đã được tạo!
⚡ Mẹo: File PDF mới (bước 3) có thể mở trực tiếp không cần mật khẩu, in được, copy text được!
